# Quickstart ⚡

This path gets you from **clone → running app** in under 90 seconds.

## Prerequisites

- **Node.js:** 20.x or higher
- **npm:** 10.x or higher

## 1) Clone & Enter

```bash
git clone https://github.com/acidgreenservers/Noosphere-Reflect.git
cd Noosphere-Reflect
```

## 2) Install Dependencies

```bash
npm install
```

## 3) Run Development Server

```bash
npm run dev
```

## 4) Access the App

Open your browser to:
**[http://localhost:3000/Noosphere-Reflect/](http://localhost:3000/Noosphere-Reflect/)**
